Game Jam - Démasqué
Création du jeu vidéo d'enquête Démasqué par une équipe de 6 personnes lors d'une game jam de 48h la Global Game Jam 2026
Détails du projet :
Le jeu est un point and click en 3D se passant dans un bal masqué. Le joueur incarne un agent du roi et doit découvrir le meurtrier du prince. Pour s'aider il pourra questionner les convives, écouter les discussions et fouiller les décors à la recherches d'indices pour désigner le coupable en fin de partie.
Lien Github du projet Page itch.io du jeu
Contexte
Jeu crée lors de la global game jam de 2026 auquel le thème était les masques. On est donc parti dans la création d'un jeu se passant lors d'un bal masqué.
Mon rôle
Développeur C#
  • Création d'un système de téléportation entre les différentes scènes.
  • Création des UI, des menus et des changements de scènes.
  • Placement et mise en places d'assets dans les scènes 3D.
