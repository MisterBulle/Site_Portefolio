Dungeon FPS
Développement du jeu vidéo FPS Dungeon FPS sous Unity en développement solo.
Détails du projets
Développement d'un FPS sous Unity intégrant plusieurs armes à feu, différents types d'ennemis ainsi qu'une mécanique de roguelike.

Entre chaque salle, le joueur doit choisir un Power-Up parmi une sélection. Ces améliorations permettent de modifier différents aspects du gameplay comme la mobilité du joueur ou le dêgat des armes.

Le jeu intègre un système d'IA permettant aux ennemis de patrouiller, de détecter et poursuivre le joueur, puis de reprendre leur patrouille s'ils le perdent.
Contexte
Lors de ma première année de Master AMINJ, j'ai réalisé seul un jeu vidéo 3D sous Unity, intégrant des éléments aléatoires.

J'ai choisi de développer un Fast FPS roguelike, un genre que je maîtrisais peu afin d'explorer de nouvelles mécaniques et d'élargir mes compétences.

L'objectif étant avant tout l'apprentissage, j'ai volontairement limité l'utilisation d'outils d'IA de complétion de code tels que Copilot.

Technologies et outils utilisées
  • C# : Développement
  • Input System avec les Actions Maps : Système permettant de facilement modifier les inputs d'actions aux claviers et à la manette.
  • Raycast Interaction : : Intéraction avec les items et les portes.
  • State Machine : Système d'IA qui change de statut (patrouille/attaque) suivant les actions du joueur.
